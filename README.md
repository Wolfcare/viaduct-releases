# Viaduct releases

Downloads for **Viaduct**, a boardview and schematic viewer for electronics
repair, built by Obscura Lux.

Go to **[Releases](../../releases/latest)** and download:

- **macOS 10.15 Catalina or later** (Apple Silicon and Intel): `Viaduct-<version>-macos-universal.dmg`
- **Windows 10 or later**: `Viaduct-<version>-windows-x64.exe` (installer) or the portable `.zip`

Viaduct checks this page for new versions and offers to install them. Each
release includes `viaduct-update.json`, which lists every installer with its
size and SHA-512 hash, and `viaduct-update.json.sig`, an Ed25519 signature of
that list. The app installs an update only if the signature and the hashes
check out.
